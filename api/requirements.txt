# Vercel serverless function dependencies.

# IMPORTANT: This list is intentionally minimal — every extra MB here counts
# against Vercel's 225 MB unzipped function-bundle limit.
#
# What was removed and why:
#   langchain / langchain-openai / langchain-core  →  replaced with direct
#       openai SDK calls in app/llm_stream.py and app/llm_invoke.py.
#       Removing the entire LangChain tree saves ~70 MB:
#         langchain, langchain-core, langchain-openai, langchain-text-splitters,
#         langsmith, tiktoken, numpy, aiohttp, orjson, requests-toolbelt
#   sqlalchemy / alembic  →  lazy-loaded and only used on the SQLite path;
#       Vercel uses Supabase REST (supabase-py), so SQLAlchemy is never
#       imported at runtime. Saves ~20 MB.
#   uvicorn  →  Vercel manages the ASGI lifecycle; uvicorn is never called.
#       Removing also drops uvloop (4 MB binary) and httptools.
#   psycopg-binary  →  already excluded; local-dev / migration tool only.
#
# Size budget (approximate unzipped):
#   pydantic + pydantic-core   ~12 MB
#   openai (incl. httpx etc.)  ~15 MB
#   fastapi + starlette        ~3 MB
#   supabase + sub-clients     ~10 MB
#   python-dotenv / pyyaml     ~1 MB
#   python stdlib              ~30 MB (Vercel baseline)
#   CPython runtime            ~40 MB (Vercel baseline)
#   ─────────────────────────────────
#   Estimated total            ~111 MB  (well under the 225 MB limit)
